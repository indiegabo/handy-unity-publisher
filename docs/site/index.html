Operate Unity releases without leaving your workstation.

HGP is a local-first desktop shell for Unity build and publish pipelines. These guides cover the workflows that ship in the beta: Windows installation, repository-backed projects, local workspaces, reusable credentials, publish destinations, and recovery paths.

Start with installation Configure publishing
Two project modes

Connect a remote repository or register a local Unity workspace. Both feed the same inspection, build-target, and publish surfaces.

Operator-owned automation

Keep the runtime healthy while switching release intake between active automation and deliberate idle posture from the shell.

Reusable credentials

Store one reusable Itch or repository credential in settings and bind it to project flows as needed.

Clear storage roots

Runtime data stays under a single host-owned root, and dev builds suffix the product directory with _DEV.

Runtime health cues

The Settings screen is the control room for shell version, runtime version, runtime directories, localization preferences, and reusable credentials.

Automation semantics

Active means polling intake continues. Idle keeps the runtime and workers healthy while blocking automatic intake until you switch back.

Documentation access

The packaged shell links back to this site from Settings so the operator does not need repository archaeology just to perform a release or recover a workstation.

Need a fast recovery path?

Start with the troubleshooting guide if Unity is not detected, repository access fails, the runtime looks unhealthy, or Itch publication prerequisites are missing.
