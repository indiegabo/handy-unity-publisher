# Settings and Credentials

Settings and credentials support the operator workflow around projects,
releases, and publication. This is where you review the environment that HGP
depends on.

## Review the settings screen

Use settings to confirm where HGP stores data and which operator-facing options
are active on the workstation.

<img src="../../assets/images/prints/settings.png" alt="Settings screen" />

Settings are especially important when:

- you are onboarding a new machine
- storage paths need to change
- runtime-managed files need to be verified
- project execution behaves differently than expected

## Manage credentials from one place

Repository access and remote publication both depend on ready credentials.

<img src="../../assets/images/prints/login-providers.png" alt="Login providers and credentials" />

Use this area when you need to:

- add access to a private Git repository
- replace expired or rotated credentials
- review which provider a project or destination expects
