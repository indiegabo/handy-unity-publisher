# Configurações e Credenciais

As configurações e credenciais dão suporte ao fluxo operacional em torno de
projetos, releases e publicação. É aqui que você revisa o ambiente do qual o
HGP depende.

## Revise a tela de configurações

Use as configurações para confirmar onde o HGP guarda dados e quais opções
voltadas ao operador estão ativas nesta workstation.

<img src="../../assets/images/prints/settings.png" alt="Tela de configurações" />

As configurações são especialmente importantes quando:

- você está preparando uma máquina nova
- os caminhos de armazenamento precisam mudar
- os arquivos gerenciados pelo runtime precisam ser verificados
- a execução de projetos está se comportando de forma diferente do esperado

## Gerencie credenciais em um só lugar

O acesso ao repositório e a publicação remota dependem de credenciais prontas.

<img src="../../assets/images/prints/login-providers.png" alt="Provedores de login e credenciais" />

Use esta área quando precisar:

- adicionar acesso a um repositório Git privado
- substituir credenciais expiradas ou rotacionadas
- revisar qual provedor um projeto ou destino espera
